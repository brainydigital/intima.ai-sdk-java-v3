# Utilidade: **Polo**

Você pode utilizar a constante de polo para melhor legibilidade do seu código, por exemplo:

```java
import ai.intima.Utilidades.Polo;

int polo = Polo.ATIVO;
```

| Constante | Valor |
| --------- | ----- |
| ATIVO     | 0     |
| PASSIVO   | 1     |
